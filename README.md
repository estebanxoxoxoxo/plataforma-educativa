# Innerith UI

UI de Innerith (React + TypeScript + Vite), portada 1:1 del prototipo `../index.html`.

```bash
npm install
SMARTY_PIN=xxxxxx npm run import:smarty -- "<ruta al smarty-all-*.json>"   # una vez: claves + listas de Smarty
npm run dev         # TODO de una: web (Vite) + API (8787) + route-lab (5203)
npm run dev:web     # solo la web
npm run dev:server  # solo lo de atrás: API + route-lab
```

`import:smarty` descifra el respaldo de Smarty con el PIN del padre y escribe `server/.env` (claves de API) y `server/data/config.json` (sitios aprobados, temas, reglas de dominio, palabras bloqueadas, prompts editados). Las dos rutas están en `.gitignore`.

Abrí con `?stage` (por ejemplo `http://localhost:5173/?stage`) para verla en el lienzo de 1280×720 escalado, igual que el prototipo, y comparar.

## Estructura

| Carpeta | Qué hay |
|---|---|
| `src/api/types.ts` | Contratos de datos (lo que el backend tiene que devolver) |
| `src/api/index.ts` | Cliente de API contra el backend (`server/`): todo real o fake DE SERVER. Pone la cabecera `X-Innerith-User` (usuario activo) en cada llamada y loguea en la consola (`[api] → GET …`) |
| `src/sections/<sección>/` | Una carpeta por punto del menú: `home`, `discover`, `learn` (Aprender = Learn: aprender + practicar + Active Recall colapsados), `create`, `leagues`… (`friends` ya no es punto del menú: es el dock de Mensajes, presente en toda la app) |
| `src/learn/` | El MOTOR de actividades del porte Smarty (W2: núcleo, los 5 Tipos con sus tableros, registry, definiciones, audio/visual) + `recall.ts` (la urgencia del Active Recall, W4). Puro: sin API |
| `…/containers/` | Pantallas y paneles que piden datos a `api` y arman la vista |
| `…/cards/` | Ítems de listas y grillas (resultado, curso, amigo, liga, opción de respuesta…) |
| `…/components/` | Piezas visuales puras (reciben props; no llaman a la API) |
| `…/lib/` | Helpers sin UI de la sección (layout del camino, formato, etc.) |
| `…/<sección>.css` | Estilos de la sección |
| `src/shared/` | Lo común a todas: barra lateral, íconos, avatar, solapas, esqueleto |
| `src/styles/` | CSS global (base y layout) |

Una sección puede usar piezas de otra: Learn lee los artículos con el lector de `discover` (`WikiArticle`) y toma las categorías de `create`.

Todas las vistas comparten UNA columna central (1040px máx, centrada), definida por `.view` en
`styles/shell.css` con los tokens `--content-w`/`--view-px`; las secciones no definen ancho de página (excepciones más
angostas, centradas en el mismo eje: reproductor 760, lector 900 y el hilo del Feed 780). Los overlays de Learn (actividad,
lectura y video de una posta) van a pantalla completa en un portal sobre `<body>`.
